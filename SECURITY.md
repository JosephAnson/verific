# Security policy

## Supported versions

Only the latest released version of Verific receives security updates.

## Reporting a vulnerability

Please report suspected vulnerabilities through a [private GitHub security
advisory](https://github.com/JosephAnson/verific/security/advisories/new). Do not
disclose vulnerability details in a public issue.

Include the affected version or versions, the potential impact, and clear steps
to reproduce the issue. Do not include secrets, credentials, or personal data in
your report.

If the private advisory route is unavailable, contact the maintainer through
[GitHub](https://github.com/JosephAnson) without posting vulnerability details
publicly.

Please allow time for investigation and coordinated disclosure before sharing
the vulnerability publicly.
